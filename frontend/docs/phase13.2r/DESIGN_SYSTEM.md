# Design System — Phase 13.2R

## Source
The CRM shell reuses the VESTRA public website design language:
- Navy primary (`#0d3b66`)
- Green secondary (`#70c050`)
- Gold accent (`#d4af37`)
- Poppins font family
- 4px spacing grid
- 8px/12px/16px/24px border radius scale

## Surfaces
- Page background: `--surface-page` (`neutral-50`)
- Cards: `--surface-card` (`white`) with `--border-default` border
- Sidebar: dark gradient (`primary-800` → `primary-900`)

## Typography
- Page title: `--text-h1` (1.75rem, bold)
- Card titles: `--text-body` (0.9375rem, semibold)
- Metrics: `--text-h1` (1.75rem, bold)
- Supporting text: `--text-body-sm` / `--text-caption`

## Components
- **Cards:** white, rounded-xl, subtle shadow, hover shadow lift.
- **KPI cards:** icon container (40px), value, trend badge.
- **Buttons:** primary navy pill, secondary white outline pill.
- **Badges:** rounded-full, semantic colours.
- **Sidebar items:** rounded-md, hover background, active gradient + left accent.
- **Header search:** pill with muted background and keyboard hint.
