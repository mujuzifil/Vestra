# Phase 13.6 — Responsive Report

## Breakpoints

- `< 640px`: single-column layouts, drawers full-width, header actions stacked
- `640px – 1023px`: KPI grid 2 columns, filter bar wraps
- `1024px+`: KPI grid 5 columns, table visible, drawers 520–560px wide

## Adaptations

- Table wrapper enables horizontal scroll on small screens
- Filter dropdowns become full-width on mobile
- Header search expands to full width below the title on narrow viewports
- Detail drawer quick actions collapse to a single column on mobile
- Form grid collapses from 2 columns to 1 column on small screens
