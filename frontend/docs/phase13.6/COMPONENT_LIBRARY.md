# Phase 13.6 — Component Library

## Backend Blade Components (`resources/views/components/companies/`)

| Component | Purpose |
|-----------|---------|
| `page-header` | Title, subtitle, search, refresh, export/import, new company |
| `kpi-cards` | 5-column grid of KPI cards |
| `filter-bar` | Status, industry, country, region, district, account manager, date range, toggles |
| `company-table` | Sortable enterprise table |
| `company-row` | Single row with avatar, badges, counts and action menu |
| `detail-drawer` | Company info, relationships, documents, activity, ticket form |
| `company-form` | Create/edit drawer form |
| `import-drawer` | CSV upload and template download |
| `pagination` | Custom pagination controls |
| `empty-state` | Premium empty state |

## Reusable Admin Components

- `x-admin.kpi-card` — metric card used across workspaces
- `x-filament::icon` — Heroicon support
- `x-filament-panels::page` — page wrapper
