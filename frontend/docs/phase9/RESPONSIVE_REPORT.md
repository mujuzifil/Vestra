# Phase 9 — Responsive Report

## Breakpoints

- Mobile: stacked hero CTAs, single-column form and map, single-column social/resource cards.
- Tablet: two-column contact cards, two-column social/resource grids.
- Desktop: four-column contact cards, form and map side-by-side, five-column resources.

## Verified Layouts

- Hero text scales with `clamp()`.
- Contact cards wrap cleanly across breakpoints.
- Map maintains a minimum height of 480 px.
- FAQ section uses a two-column layout on desktop.
