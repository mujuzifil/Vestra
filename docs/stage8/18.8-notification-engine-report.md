# Stage 18.8 — Notification Engine Report

## Overview

The VESTRA Notification & Communication Center is an event-driven engine that centralizes all customer, distributor, and administrator notifications. It supports email, SMS, in-app, and future channels through a provider abstraction layer.

## Architecture

```
Application Event
        │
        ▼
NotificationDispatcherService
        │
 ┌──────┼───────────────┐
 │      │               │
 ▼      ▼               ▼
Email   SMS      In-App Notification
        │
        ▼
NotificationDelivery (audit log)
```

## Core Components

| Component | Purpose | Path |
|-----------|---------|------|
| NotificationDispatcherService | Central dispatcher | `backend/app/Services/NotificationDispatcherService.php` |
| NotificationTemplateService | Template resolution & rendering | `backend/app/Services/NotificationTemplateService.php` |
| NotificationPreferenceService | User preference enforcement | `backend/app/Services/NotificationPreferenceService.php` |
| NotificationDeliveryService | Delivery audit logging | `backend/app/Services/NotificationDeliveryService.php` |
| EmailNotificationService | Queued email dispatch | `backend/app/Services/EmailNotificationService.php` |
| SmsNotificationService | SMS dispatch | `backend/app/Services/SmsNotificationService.php` |
| AnnouncementService | Broadcast announcements | `backend/app/Services/AnnouncementService.php` |
| SystemNotification | Laravel notification class | `backend/app/Notifications/SystemNotification.php` |

## Channels

- `email` — queued transactional email via Laravel Mail
- `sms` — provider-based SMS (default `LogSmsProvider`)
- `in_app` — Laravel database notifications
- `push` — future-ready placeholder
- `whatsapp`, `webhook` — future-ready enums

## Events

The engine listens to 22 application events including customer registration, order lifecycle, distributor onboarding, quotations, payments, credit updates, and system maintenance.

## Outcome

The notification engine is reusable across all future platform modules and respects per-user channel and topic preferences.
