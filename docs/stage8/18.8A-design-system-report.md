# Stage 18.8A — Design System Report

## Objective
Establish a single, authoritative VESTRA design system shared by the Public Website, Customer Portal, Distributor Portal, Notification Center, Authentication pages, and Filament Admin.

## Source of truth
The canonical tokens live in `backend/resources/css/filament/admin/tokens/` and are mirrored into the frontend via:

- `frontend/styles/tokens.css` — raw CSS custom properties
- `frontend/styles/motion.css` — animation and transition utilities
- `frontend/app/globals.css` — Tailwind v4 `@theme inline` utility mappings

## Token categories

| Category | File | Scope |
|----------|------|-------|
| Colors | `tokens/colors.css` | Primary (navy), secondary (green), accent (gold), semantic, neutral, surfaces, text, borders |
| Typography | `tokens/typography.css` | Font families, type scale, line heights, letter spacing, weights |
| Spacing | `tokens/spacing.css` | 4px grid, layout dimensions (sidebar, topbar, max-width) |
| Radius | `tokens/radius.css` | sm → full |
| Elevation | `tokens/elevation.css` | Shadows, opacity values |
| Motion | `tokens/motion.css` | Easings and durations |

## Semantic tokens
Semantic aliases decouple components from raw palette values:

- `--surface-page`, `--surface-card`, `--surface-sidebar`
- `--text-heading`, `--text-body`, `--text-muted`, `--text-placeholder`
- `--border-default`, `--border-hover`, `--border-focus`, `--border-error`

## Alignment between frontend and admin
`frontend/styles/tokens.css` is a verbatim mirror of the Filament token set plus frontend-specific aliases (`--navbar-height`, `--color-hero-bg`, WhatsApp brand color). Both admin and frontend now resolve identical values from the same source.

## Hardcoded color reduction
- Before Stage 18.8A: **1,503 hardcoded hex occurrences** across **91 `.tsx` files**
- After Stage 18.8A: **1 remaining occurrence** (`#10047` HTML entity in `vision-banner-section.tsx`, not a color)
