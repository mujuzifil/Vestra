# Stage 18.8 — Announcement Center Report

## Implementation

Administrators can publish announcements targeted to specific audiences.

## Key Files

- `backend/app/Models/Announcement.php`
- `backend/app/Services/AnnouncementService.php`
- `backend/app/Filament/Resources/AnnouncementResource.php`
- `backend/app/Http/Controllers/Api/V1/AnnouncementController.php`
- `backend/app/Http/Controllers/Api/V1/Admin/AnnouncementController.php`

## Features

- Audience targeting: Everyone, Customers, Distributors, Admins
- Priority levels: low, normal, high, critical
- Pinned announcements
- Start/end dates
- Scheduled publishing
- Broadcast action in Filament

## Lifecycle

```
Draft / Scheduled
      ↓
   sent_at set
      ↓
Broadcast to target audience
      ↓
Delivered via email + in-app
```

## Scheduling

`ProcessScheduledAnnouncementsJob` runs every 5 minutes via Laravel schedule.

## Outcome

Announcements are fully managed in Filament and delivered to authenticated users through the API.
