# Stage 18.8A — Responsive Design Report

## Objective
Ensure every portal provides a consistent, usable experience across desktop, laptop, tablet, and mobile.

## Breakpoints
Standard Tailwind v4 breakpoints are used throughout:
- `sm`: 640px
- `md`: 768px
- `lg`: 1024px
- `xl`: 1280px
- `2xl`: 1536px

## Layout behavior

### Public Website
- Navbar collapses to hamburger menu below `lg`
- Container max-width: 1320px
- Footer stacks from 4 columns to 1 on mobile

### Customer Portal
- Sidebar hidden on mobile; hamburger toggle in top-left
- Sidebar drawer slides in from the left
- Main content padding reduces on smaller screens (`p-4` → `lg:p-8`)

### Distributor Portal
- Same sidebar/drawer pattern as customer portal
- Sticky sidebar on desktop at `top-[88px]`
- Tables wrapped in `overflow-x-auto`

## Components
- `DataTable` scrolls horizontally on narrow viewports
- `Modal` uses `max-w-md` and viewport padding
- `Drawer` uses `max-w-md` width and full height
- `PageHeader` stacks title and actions vertically on mobile

## Touch targets
All interactive elements maintain at least 40×40px tap targets.

## Status
✅ Responsive patterns standardized across all portals.
