# Stage 18.8 — Email Service Report

## Implementation

Email notifications use Laravel's queued Mail with a shared branded layout.

## Key Files

- `backend/app/Mail/TemplateMailable.php`
- `backend/resources/views/emails/layout.blade.php`
- `backend/resources/views/emails/template.blade.php`
- `backend/resources/views/emails/template_plain.blade.php`
- `backend/app/Services/EmailNotificationService.php`

## Features

- Shared responsive HTML layout with VESTRA branding
- `{{variable}}` placeholder replacement
- Queued delivery via `Mail::to()->queue()`
- Plain-text fallback
- Template-based subject lines

## Template Rendering

`NotificationTemplateService::renderTemplate()` replaces variables for:
- `subject`
- `email_body`

## Default Templates

Seeded via `NotificationTemplateSeeder` for:
- Customer registration
- Order created / paid / shipped / delivered / cancelled
- Distributor application submitted / approved / rejected
- Password changed
- Admin announcements
- System maintenance

## Outcome

Email channel is production-ready. Future work: integrate SendGrid/Postmark/Mailgun via Laravel mail driver configuration.
