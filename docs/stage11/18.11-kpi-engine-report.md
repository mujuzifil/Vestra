# Stage 18.11 — KPI Engine Report

## Overview

The KPI engine is implemented as an extension of `ReportService` with aggregate methods returning standardized, cacheable arrays. It powers the executive dashboard, report pages, and REST API.

## Key Performance Indicators

### Revenue
- Total revenue, previous-period comparison, change percentage
- Average order value
- Revenue by payment method and order status

### Sales
- Paid, total, cancelled, refunded orders
- Units sold
- Best sellers, worst performers, category breakdown

### Customers
- Total, new this month, repeat, inactive
- Repeat customer percentage
- Average customer value

### Inventory
- Total value, total units, product count
- Low stock and out-of-stock counts

### Distributors
- Applications, pending review, approved, rejected
- Approval rate

### Engagement
- Reviews, feedback, contact messages
- Average rating, pending reviews

### Finance
- Total invoiced, total paid, total overdue
- Outstanding credit and total credit limit

## Caching Strategy

- 1-hour TTL for all aggregates.
- Cache keys include report name, date range, and filter hash.
- Dashboard widgets use their own cache keys with shorter TTLs where appropriate.
