# Stage 18.11 — Forecasting Report

## Overview

A lightweight forecasting engine was added to project revenue, orders, inventory stockouts, customer growth, and distributor growth based on recent historical data. No external ML libraries are required.

## Implementation

`App\Services\ForecastingService` provides:

- `revenueForecast($days)` — weighted moving average + linear regression on daily paid revenue.
- `orderForecast($days)` — same approach for order counts.
- `inventoryForecast($days)` — projects stockouts based on 30-day sales velocity.
- `customerGrowthForecast($months)` — monthly new-customer regression.
- `distributorGrowthForecast($months)` — monthly application regression.

## Algorithm

1. Collect historical daily/monthly data.
2. Compute linear regression trend line.
3. Compute weighted moving average over recent window.
4. Blend 60% WMA + 40% trend for the final projection.
5. Floor results at zero.

## Usage

Forecast data is exposed via:
- `GET /api/v1/reports/forecast`
- Filament `ForecastReport` page
- `ForecastWidget` on the executive dashboard
