# Stage 18.11 — Monitoring Report

## Overview

Operational monitoring capabilities were added to track queue health, failed jobs, scheduler status, storage, cache, and notification delivery metrics.

## Capabilities

### Queue Health
- Failed jobs in the last 24 hours
- Pending jobs count
- Status: `healthy` or `warning`

### Recent Failed Jobs
- Connection, queue, exception summary, failure timestamp

### Scheduler Status
- Last recorded scheduler run
- Health check based on run recency

### Storage Status
- Path, free/total bytes, used percentage

### Cache Status
- Driver, prefix, reachability flag

### Notification Delivery
- Total notifications, read count, read rate

## Filament Page

`OperationalMonitoringReport` renders all monitoring data in a single view with exportable failed-jobs table.

## Scheduled Maintenance

- `CleanupApiRequestLogsJob` runs weekly and removes API request logs older than 90 days.
- Scheduler heartbeat is recorded every minute.
