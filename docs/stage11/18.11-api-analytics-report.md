# Stage 18.11 — API Analytics Report

## Overview

API request analytics are captured for authenticated and admin routes via the `LogApiRequest` middleware and aggregated by `ApiAnalyticsService`.

## Data Captured

- User ID (nullable)
- HTTP method and path
- Response status code
- Request duration in milliseconds
- IP address and user agent
- Timestamp

## Middleware Registration

- Alias `log.api` registered in `bootstrap/app.php`.
- Applied to all `/reports/*` routes under `auth:sanctum`.

## Endpoints

- `GET /api/v1/reports/api-analytics` — full summary

## Metrics

- Request volume per day
- Top endpoints by request count
- Error rate trend
- Average latency trend
- Authentication failure rate

## Performance

- Lightweight table schema with indexes on date, method, path, status, and user.
- Automatic cleanup of logs older than 90 days.
