# Stage 18.11 — Security Report

## Authorization

- All report endpoints require `auth:sanctum` and `can:view reports`.
- Filament report pages use `canAccess()` to restrict to admin users.
- Dashboard widgets inherit Filament authorization.

## Data Access

- API analytics middleware only logs authenticated/admin routes.
- Customer and distributor intelligence respects existing model relationships and ownership.
- No raw customer PII is exposed in reports beyond what existing models already expose.

## Input Validation

- `ReportController` validates date ranges and limits.
- Granularity and period parameters are restricted to allowed values.

## Export Security

- PDF/Excel exports use the same authorization as the report pages.
- Filenames are sanitized via the existing `getExportFilename` helper.

## Audit

- API request logs capture IP, user agent, and status codes for security review.
- Scheduled jobs are logged via Laravel's queue and failed-job handling.
