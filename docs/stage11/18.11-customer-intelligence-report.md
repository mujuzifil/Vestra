# Stage 18.11 — Customer Intelligence Report

## Overview

Customer intelligence provides segmentation, lifetime value, retention, churn, and regional analysis to support marketing and sales decisions.

## Segmentation Logic

| Segment | Rule |
|---------|------|
| VIP | Lifetime spend ≥ UGX 500,000 OR ≥ 5 orders |
| Loyal | ≥ 2 orders and last order within 90 days |
| New | No orders or last order within 30 days |
| At Risk | Last order between 90 and 180 days |
| Lost | Last order > 180 days or never ordered |

## Metrics

- Customer Lifetime Value (CLV)
- Retention rate (period-over-period)
- Churn rate (90-day window)
- Top customer regions by revenue
- Customer activity timeline

## Filament Page

`CustomerIntelligenceReport` displays segment distribution chart, CLV table, and regional breakdown.

## API

- `GET /api/v1/reports/customer-intelligence`
