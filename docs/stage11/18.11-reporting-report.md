# Stage 18.11 — Reporting Report

## Overview

The reporting module now provides dedicated Filament pages for every major business domain, each supporting CSV, PDF, and Excel export.

## New Report Pages

| Page | Icon | Description |
|------|------|-------------|
| Forecasting | arrow-trending-up | Revenue, order, inventory, and growth forecasts |
| Customer Intelligence | user-group | Segments, CLV, retention, churn, regions |
| Distributor Intelligence | building-office | Revenue, credit, outstanding balances |
| Inventory Intelligence | cube-transparent | Turnover, valuation, warehouses, dead stock |
| API Analytics | signal | Request volume, endpoints, latency, errors |
| Operational Monitoring | server-stack | Queue, scheduler, storage, cache, notifications |

## Export Formats

- **CSV** — streaming export, UTF-8 BOM for Excel compatibility.
- **PDF** — branded VESTRA template via `laravel-dompdf`.
- **Excel** — styled workbook via `maatwebsite/excel`.
- **Printable HTML** — browser-print ready view.
