# Stage 18.11 — Distributor Intelligence Report

## Overview

Distributor intelligence tracks B2B performance including revenue, orders, credit utilization, and outstanding balances.

## Metrics

- Distributor revenue and order counts by period
- Credit limit, balance, authorized amount, available credit
- Credit utilization percentage
- Total outstanding balances
- Performance trend (orders vs applications)

## Filament Page

`DistributorIntelligenceReport` shows finance KPIs, performance trend chart, and detailed tables.

## API

- `GET /api/v1/reports/distributors`
- `GET /api/v1/reports/distributor-intelligence`
