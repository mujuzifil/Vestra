## Deployment Mechanism

The repository includes two deployment paths:

### GitHub Actions (Recommended)

`.github/workflows/deploy.yml` builds Docker images and deploys to the VPS on push to `main`/`master` or via `workflow_dispatch`.

### Manual SSH Runbook

```bash
ssh <user>@<host>
cd /opt/vestra
./scripts/backup.sh /opt/vestra/backups
git fetch origin
git checkout develop -- docker-compose.prod.yml nginx scripts
sed -i "s|^IMAGE_TAG=.*|IMAGE_TAG=<COMMIT_SHA>|" .env.production
docker compose -f docker-compose.prod.yml --env-file .env.production pull
docker compose -f docker-compose.prod.yml --env-file .env.production \
  run --rm --entrypoint php backend artisan migrate --force
docker compose -f docker-compose.prod.yml --env-file .env.production up -d
```
