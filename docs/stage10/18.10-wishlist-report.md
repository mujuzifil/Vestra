# Stage 18.10 — Wishlist Report

## Overview
A full wishlist experience supports saving products, managing lists, moving items to cart, and guest/localStorage support with server merge on login.

## Backend
- Migration: `create_wishlists_table` with support for list names and notes.
- Model/Controller: `WishlistController` with index, store, destroy, merge, and move-to-cart.
- Routes: `/api/v1/auth/wishlist*` (authenticated).

## Frontend
- `WishlistContext` synchronises guest wishlist via localStorage and merges on login.
- `/account/wishlist` page with tabs for Wishlist and Saved for Later.
- Product detail page includes Add to Wishlist button with state feedback.

## Future Enhancements
- Multiple named wishlists with sharing and public/private visibility.
- Price-drop email alerts tied to wishlist items.
