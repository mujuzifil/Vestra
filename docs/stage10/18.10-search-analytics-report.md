# Stage 18.10 — Search Analytics Report

## Overview
Search behaviour is tracked for continuous optimisation.

## Data Model
- `search_analytics` table records term, user/session, result count, clicked product, conversion, and timestamp.

## API
- `GET /api/v1/search/popular` — top terms in the last 30 days.
- `GET /api/v1/admin/search-analytics` — full analytics (admin only).

## Admin UI
- Filament page `SearchAnalytics` displays summary cards, top terms table, and a daily trend chart.

## Future Enhancements
- Zero-result search alerts.
- A/B testing of ranking algorithms.
- Meilisearch/Elasticsearch provider swap without application changes.
