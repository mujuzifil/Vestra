# Stage 18.10 — API Report

## New Endpoints

### Reviews
- `GET /api/v1/products/{slug}/reviews`
- `POST /api/v1/reviews`
- `PUT /api/v1/reviews/{review}`
- `DELETE /api/v1/reviews/{review}`
- `GET /api/v1/auth/reviews`
- `POST /api/v1/reviews/{review}/helpful`
- `POST /api/v1/reviews/{review}/report`
- `GET /api/v1/admin/reviews`
- `PUT /api/v1/admin/reviews/{review}/status`
- `POST /api/v1/admin/reviews/{review}/reply`

### Wishlist & Saved Items
- `GET /api/v1/auth/wishlist`
- `POST /api/v1/auth/wishlist`
- `POST /api/v1/auth/wishlist/merge`
- `DELETE /api/v1/auth/wishlist/{product}`
- `POST /api/v1/auth/wishlist/{product}/move-to-cart`
- `GET /api/v1/auth/saved-for-later`
- `POST /api/v1/auth/saved-for-later`
- `POST /api/v1/auth/saved-for-later/merge`
- `DELETE /api/v1/auth/saved-for-later/{product}`
- `POST /api/v1/auth/saved-for-later/{product}/move-to-cart`

### Recently Viewed
- `GET /api/v1/auth/recently-viewed`
- `POST /api/v1/auth/recently-viewed`
- `DELETE /api/v1/auth/recently-viewed/{product}`
- `DELETE /api/v1/auth/recently-viewed`

### Search & Recommendations
- `GET /api/v1/search/autocomplete`
- `GET /api/v1/search/popular`
- `GET /api/v1/admin/search-analytics`
- `GET /api/v1/recommendations`
- `GET /api/v1/products/{slug}/recommendations`

All endpoints follow existing V1 conventions: standardized resources, form requests, policies, and authentication.
