# Stage 18.10 — Recommendation Engine Report

## Overview
A `RecommendationService` delivers personalised and contextual product suggestions.

## Algorithms
- **Related products**: same category or overlapping tags.
- **Frequently bought together**: co-occurrence in orders.
- **Best sellers**: top products by total ordered quantity.
- **Trending**: top sellers in the last 30 days.
- **New arrivals**: recently created products.
- **Recently viewed**: per-user history with trending fallback.

## API
- `GET /api/v1/recommendations` — home-page collections.
- `GET /api/v1/products/{slug}/recommendations` — product-page related and frequently bought together.

## Frontend
- Home featured products now render best sellers.
- Product detail page shows related products and frequently bought together sections.
