# Stage 18.10 — Saved Items Report

## Overview
Saved-for-later lets customers preserve cart items they are not ready to purchase.

## Backend
- Migration: `create_saved_items_table`.
- Controller: `SavedItemController` with store, destroy, merge, and move-to-cart.

## Frontend
- Cart page now provides a working Save for Later action for each item.
- Saved items appear on the `/account/wishlist` page and can be moved back to cart.
- Guest saved items persist in localStorage and merge after login.
