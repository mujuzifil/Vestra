# Stage 18.10 — Recently Viewed Report

## Overview
Authenticated browsing history is now synced to the backend, enabling cross-device resume and better recommendations.

## Backend
- Migration: `create_recently_viewed_products_table`.
- Controller: `RecentlyViewedController` with index, store, destroy, and clear.
- Unique user-product index avoids duplicates; `viewed_at` is refreshed on each view.

## Frontend
- Product page records views for authenticated users via `useRecordProductView`.
- `/account/recently-viewed` page displays history with remove and clear-all actions.
- Guest history remains in localStorage for immediate UX.
