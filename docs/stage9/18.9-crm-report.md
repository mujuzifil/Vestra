# Stage 18.9 — CRM Report

## Objective
Provide customer relationship tools for the admin team.

## Features
- Customer notes with type classification (general, support, sales, internal).
- Customer tags/segments with color coding.
- Customer activity timeline via AuditLog relation manager.
- CustomerResource filters by tag, lifetime spend, and order count.
- Bulk tag assignment and removal.
